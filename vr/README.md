# Embodiment Lab VR — Rubber Hand Illusion
Self-contained Godot 4.7.2 OpenXR demonstration; no binary assets or external addons needed.

## Controls
- Right trigger (or Space on desktop): advance experiment.
- Left trigger (or 1 / 2 / 3 on desktop): choose synchronous, asynchronous or visual-only condition.
- During the questionnaire, keyboard 1–7 sets the ownership rating. Right trigger confirms.
- Duration: 45 seconds. Controller vibration is not equivalent to skin stroking.
- Session CSV is saved to `user://embodiment_lab_results.csv` on the device.

## Safety and scope
Seated demo. Ensure real-world clearance. No clinical claims; this is a simulation for research demonstrations, not a validated diagnostic instrument. Different Android VR devices must be tested individually.
